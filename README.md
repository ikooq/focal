# focal — локальное пространство внимания

Версия 0.3.0. Задачи, календарь, заметки и таймер фокуса на одном компьютере. React 19, TypeScript, Vinext/Vite, Node.js и SQLite. Интерфейс на русском, валюта финансового календаря — KZT.

Новое в 0.3: глобальный быстрый ввод, повторения, ожидание и зависимости, канбан, метки и представления, массовые действия, корзина и загрузка дня. Подробности: [RELEASE-0.3.md](RELEASE-0.3.md).

## Запуск в Windows

Установщик: `desktop-release/focal Setup 0.3.0.exe`. Он устанавливает приложение для текущего пользователя; отдельный Node.js для настольной версии не нужен.

Без установки: `desktop-release/win-unpacked/focal.exe`. Переносите всю папку `win-unpacked`, а не один exe. База и модели хранятся отдельно от приложения, поэтому обновление сборки их не заменяет.

Окно закрывается в трей. Полный выход — через меню значка. Автозапуск включается в разделе «Настройки». При занятом порте 3000 завершите прежний экземпляр сервера. Подробности ошибки запуска записываются в `%LOCALAPPDATA%/focal/logs/startup.log`.

Для браузерной версии откройте `start.cmd`, затем http://127.0.0.1:3000/. Нужен Node.js 22.13 или новее. Пока работает сервер, не закрывайте его окно.

## Ежедневная работа

- **Сегодня:** три главных дела, ближайшая встреча, продолжение таймера и краткий итог. Предложение следующей задачи не подставляет дела, отложенные на будущие дни.
- **Быстрая задача:** достаточно названия. Время, энергия, тип работы и срок находятся в дополнительных параметрах. Добровольный штраф раскрывается отдельно.
- **Фокус:** подготовка, работа и отдых; короткие режимы на 5 и 15 минут. Пауза останавливает отсчёт и звук, сохраняется после перезапуска и не засчитывается в рабочее время. Сворачивание сохраняет ход таймера. Цикл и завершение самой задачи — разные действия.
- **Просрочка:** задача остаётся доступна для работы. Можно закончить её, изменить срок или перенести план. История сессий сохраняется.
- **Завершить день:** выбрать судьбу оставшихся запланированных дел, сохранить заметку об итогах, назначить первое дело на завтра и конкретный следующий шаг. Все изменения применяются вместе. Сроки и календарные встречи не переносятся автоматически.
- **Задачи → Проекты:** цели, задачи, подзадачи, прогресс и архив. Родительскую задачу можно завершить после подзадач.
- **Календарь:** недельное расписание, повторения, редактирование и перемещение блоков, отмена, шаблоны недели и подбор свободного времени. Объёмная неделя доступна как дополнительное представление.
- **Заметки и материалы:** записи по датам, черновики, создание задач из текста, ссылки и вложения. Один файл до 8 МБ, суммарно до 40 МБ.
- **Обзор недели:** план и фактический фокус, выполненные дела и оценки времени. Паузы исключаются, работа через полночь распределяется по дням.
- **Привычки и решения:** отметки привычек по дням, разбор решений и входящие мысли. Проекты находятся рядом с задачами.
- **Настройки:** видимые разделы, рабочие часы, анимации, резервные копии и автозапуск Windows. Скрытие раздела не удаляет его данные.

## Финансы и условные штрафы

Прогноз и календарь учитывают реальные и запланированные доходы/расходы. Регулярные платежи поддерживают недели и месяцы, включая короткие месяцы. Проведение операции не создаёт дубль.

Условные штрафы хранятся в отдельной раскрываемой истории раздела «Финансы» и не уменьшают денежный остаток. Если расход действительно состоялся, его можно явно провести текущей датой. Приложение не совершает банковских списаний. Повторная просрочка или остановка той же задачи не создаёт второй штраф.

## Помощник и локальные модели

«Помощник» содержит перепланирование дня, сценарии недели, быстрый разбор текста, OCR, голос, импорт/экспорт ICS и поиск по истории. Изменения расписания требуют применения предпросмотра; устаревший план отклоняется.

Используются Tesseract rus+eng, faster-whisper small на CPU и Ollama с `qwen3:4b` либо `focal-qwen:latest`. Обработка локальная. Модели не входят в установщик и в SQLite-копию. На этом компьютере существующие модели и среда распознавания перенесены в пользовательский каталог. На другом компьютере их нужно подготовить отдельно; базовые задачи, календарь и таймер работают без них. Голосу требуется установленный базовый Python, на который ссылается его среда.

## Данные и резервные копии

Основная база: `%LOCALAPPDATA%/focal/data/focal.sqlite`.
Модели: `%LOCALAPPDATA%/focal/data/models`.
Среда голоса: `%LOCALAPPDATA%/focal/data/voice-env`.

При первом запуске из старого проекта база копируется согласованно с учётом WAL, а модели и среда голоса переносятся копированием. Исходная папка сохраняется. Существующая база в пользовательском каталоге никогда не заменяется автоматически. После перехода не запускайте прежнюю версию: она использует старую папку данных.

Схема версии 6 обновляется автоматически. Перед миграцией сохраняется копия. Старые незавершённые задачи становятся доступными для продолжения, исторические условные штрафы отделяются от проведённых расходов. Новые поля workflow добавляются без удаления пользовательских данных.

Автоматическая копия создаётся ежедневно, пока работает локальный сервер. Хранятся последние 14 автоматических копий; ручные и миграционные копии не удаляются. Папку можно изменить в настройках, в Windows доступен системный выбор папки. Ошибки копирования отображаются в настройках.

Скачать или восстановить SQLite-копию можно из настроек или нижней панели. Восстановление сначала проверяет файл и показывает состав данных, затем создаёт копию текущей базы. Ручное подменивание SQLite/WAL/SHM при работающем приложении не требуется.

Для разработки и тестов доступны переменные `FOCAL_DATA_PATH`, `FOCAL_DATA_DIR`, `FOCAL_SUPPORT_DIR`, `PORT`. С заданным `FOCAL_DATA_PATH` автоматический импорт прежних данных не выполняется.

## Разработка и проверки

```powershell
npm install
npm run dev
npm test
npm run typecheck
npm run lint
npm run build
npm run test:e2e
npm run desktop:build
```

Сквозные тесты используют установленный Chrome, отдельный сервер на порте 3107 и временную базу; пользовательские записи не затрагиваются. Отчёт и снимки находятся в `output/playwright`. `npm run test:e2e` запускается после сборки.

Обмен состоянием использует ETag: неизменившаяся история не скачивается каждые 15 секунд. Посекундный отсчёт изолирован в компоненте фокуса, корневые временные показатели обновляются раз в минуту. Помощник и финансовый график загружаются по требованию.

Основные модули: `hooks/use-focal-data.ts` — загрузка и изменения; `app/focus-overlay.tsx` — таймер; `app/task-fields.tsx` — форма задачи; `server/session-actions.mjs` — жизненный цикл сессий; `server/day-actions.mjs` — завершение дня; `server/backup-restore.mjs` и `server/auto-backup.mjs` — резервное копирование.
